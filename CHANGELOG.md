# Changelog

## 1.1.0 - 2026-10-11

### Added
- Repositories needing attention (update available, warning, error, not cloned) are listed first.
- Progress bars show the repository currently being processed and briefly show each clone/update completion.
- Console log lines with date/time and app version for debugging.

### Changed
- All buttons and inputs are disabled while a clone, refresh, or update is running.
